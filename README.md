**Starshard Arena** is a neon arena survival game for the desktop browser. Pilot a lone shard-ship against the Hollow — seven named kinds of geometric hunter, each with its own face and temper: Stalkers that never stop coming, Lances that lunge, Broods that burst into Mites, Wraiths that weave and spit plasma, bone-plated Bulwarks, Stingers that duel at range, and every fifth wave the Dreadnought, a siege-moon that charges, broods Mites and enrages at half hull. Kills drop more than points: the Hollow leave **skill Cores** — Overdrive, Seeker Missiles, Piercing Bolts, a Nova Burst — that you steal by flying over the wreck, mid-fight. But the swarm eats too: a Hollow that reaches your dropped shards first swallows them and grows. Chain kills into a combo to charge the screen-clearing **Starfall**, dash through danger and leave a burning ion wake, fight inside gravity **rifts** that drag friend and foe alike, and between waves spend your shards at the Forge, where every permanent upgrade is bought with the remains of the ships you broke — or banked toward something bigger. Every run forges a different ship. Keyboard and mouse, procedural WebAudio sound, no build step and no network: the whole game is the static files in `game/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click LAUNCH. (To package the entry instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.)
