**Starshard Arena** is a neon arena survival game for the desktop browser. Pilot a lone shard-ship against the Hollow — five named kinds of geometric hunter, each with its own face and temper: Stalkers that never stop coming, Lances that lunge, Broods that burst into Mites, Wraiths that weave and spit plasma, and every fifth wave the Dreadnought, a siege-moon that charges, broods Mites and answers with fans of plasma. Break them, catch the star shards they drop, chain kills into a combo multiplier — then spend those shards at the Forge between waves, where every upgrade (twin cannons, heavy bolts, an Aegis shield, a shard magnet and more) is bought with the remains of the ships you broke, or banked toward something bigger. Every run forges a different ship. Keyboard and mouse, procedural WebAudio sound, no build step and no network: the whole game is the static files in `game/`.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 and click LAUNCH. (To package the entry instead: `mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts`.)
